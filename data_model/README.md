# Data Model

Knowledge graphs, schemas, and other data models that back platform intelligence across
[CivicDataSpace](https://civicdataspace.in) — how datasets, collaboratives, and canonical entities relate to
each other, independent of any single collaborative's own domain model.

```
data_model/
├── knowledge-graph/   Entity/relationship definitions and any graph-building tooling
└── schemas/           Shared schemas (e.g. dataset metadata, collaborative manifest) referenced by
                        audits/cds-audit and by collaboratives
```

Both directories are placeholders until the first knowledge graph / schema lands here.
